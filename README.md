
# المنصة التعليمية الشاملة للمعلم الفلسطيني — نسخة محلية مكتملة

هذه النسخة **محلية بالكامل** وتعمل بخمسة ملفات فقط:

١. `index.html`
٢. `styles.css`
٣. `generators.js`
٤. `app.js`
٥. `README.md`

## ما الذي تقدمه هذه النسخة؟
- رفع أي كتاب مدرسي PDF من جهاز المستخدم.
- قراءة الصفحات والتنقل بينها داخل المتصفح.
- استخراج نص الصفحة الحالية أو إدخال النص يدويًا.
- توليد مستندات متكاملة قابلة للتعديل والطباعة:
  - تحضير درس
  - ورقة عمل
  - اختبار قصير
  - قائمة رصد ومتابعة
  - متطلبات الإدارة والإشراف
  - خطة شهرية / فصلية مختصرة
- حفظ محلي واستعادة فورية.
- تصدير واستيراد البيانات بصيغة JSON.
- تنزيل نسخة HTML مكتملة بعد التعديل.

## التشغيل السريع
١. افتح `index.html`.
٢. أدخل بيانات المعلم والمدرسة.
٣. ارفع ملف PDF للكتاب المدرسي.
٤. استخرج نص الصفحة الحالية أو الصق النص يدويًا.
٥. اختر نوع المخرج ثم اضغط التوليد.
٦. عدّل المحتوى داخل الصفحة مباشرة.
٧. اطبع أو خزّن أو نزّل نسخة HTML.

## ملاحظات مهمة
- إذا كان الكتاب صورة ممسوحة بلا نص قابل للاستخراج، الصق النص يدويًا في خانة المقتطف المعتمد.
- النسخة لا تحتوي أي ربط خارجي، وكل العمل محلي داخل المتصفح.
- التطوير اللاحق سهل بإضافة مولدات جديدة داخل `generators.js` وربطها من `app.js`.
