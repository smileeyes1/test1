
# المنصة التعليمية الشاملة للمعلم الفلسطيني — إصدار عملي حقيقي

هذا المشروع **ثابت** وجاهز للنشر على **GitHub Pages** باستخدام **خمسة ملفات فقط**:

١. `index.html`
٢. `styles.css`
٣. `generators.js`
٤. `app.js`
٥. `README.md`

## ما يقدمه المشروع فعليًا
- رفع **أي كتاب مدرسي PDF** من جهاز المستخدم.
- عرض صفحات الكتاب والتنقل بينها.
- استخراج نص الصفحة الحالية داخل المتصفح.
- توليد مستندات قابلة للتعديل والطباعة:
  - تحضير درس
  - ورقة عمل
  - اختبار قصير
  - قائمة رصد ومتابعة
  - تقرير ومتطلبات الإدارة والإشراف
  - خطة متابعة شهرية / فصلية مختصرة
- حفظ محلي واستعادة وتصدير/استيراد بيانات.
- **ربط GitHub حقيقي** من داخل الصفحة إلى مستودع باسم **`test1`** باستخدام **GitHub Personal Access Token** يقدمه المستخدم.

## ما الذي يحتاجه زر النشر الحقيقي؟
لكي يقوم الزر بإنشاء المستودع `test1` أو تحديثه تلقائيًا، يحتاج المستخدم إلى:
- اسم مستخدم GitHub
- Personal Access Token بصلاحيات مناسبة مثل:
  - `repo`
  - ويفضل أيضًا صلاحية Pages إن كان الحساب يتطلب ذلك لإتاحة GitHub Pages

## ماذا يفعل زر النشر؟
- يتحقق من وجود المستودع `test1`
- ينشئه إن لم يكن موجودًا
- يرفع الملفات الخمسة إليه تلقائيًا
- يحاول تفعيل GitHub Pages على الفرع `main`
- يعرض رابط الموقع المتوقع بالشكل:
  - `https://USERNAME.github.io/test1/`

## حدود من المهم معرفتها بصدق
- نجاح تفعيل Pages تلقائيًا يعتمد على صلاحيات الـ Token وسياسات GitHub للحساب.
- إذا رفض GitHub تفعيل Pages تلقائيًا، تبقى الملفات مرفوعة بنجاح غالبًا، ويمكن تفعيل Pages يدويًا من إعدادات المستودع.
- المنصة لا تحتوي ذكاءً سحابيًا خارجيًا تلقائيًا؛ التوليد الحالي داخل المنصة **قالبـي عملي منظم** وموجه للاستخدام التعليمي الفوري.

## تشغيل سريع
١. افتح `index.html`.
٢. أدخل بيانات المعلم والمدرسة.
٣. ارفع كتاب PDF.
٤. استخرج نص الصفحة.
٥. اضغط `توليد الحزمة الكاملة` أو النوع المطلوب.
٦. للطباعة: اضغط `طباعة`.
٧. للنشر على GitHub داخل المستودع `test1`: أدخل اسم المستخدم وToken ثم اضغط `إنشاء/تحديث test1 تلقائيًا`.
