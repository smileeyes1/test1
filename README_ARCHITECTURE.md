
# الوثيقة المعمارية النهائية

## الطبقات
١. طبقة الواجهة: عرض وتشغيل وتحرير ومساعد مدمج.
٢. طبقة الذكاء: محلي قاعدي + مزودات API خارجية + رجوع تلقائي.
٣. طبقة الجسر الخلفي: تنفيذ آمن محكوم بسياسة أوامر وأدوار.
٤. طبقة التشغيل: Queue + Audit + Emergency Stop + Idempotency.
٥. طبقة التكامل المؤسسي: eSchool بحالة جاهزية مؤسسية تتطلب اعتمادات رسمية.

## القاعدة
- اعتمد المرجع المتحقق والسياسات الرسمية فقط.
- أصلح مسارات الفشل والصلاحيات قبل التوسع.
- أكمل التنفيذ والتكامل تدريجيًا بطريقة آمنة.
